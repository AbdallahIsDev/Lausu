Local privacy architecture, zero telemetry

Lausu splits a native Rust Tauri shell from an isolated local ONNX worker over loopback IPC. Audio buffers stay in memory, transcripts live in local SQLite, and provider keys never touch plaintext JSON.

  • Zero analytics SDKs, crash beacons, or background pings
  • Windows Credential Manager, macOS Keychain, and Linux Secret Service
  • Opt-in cloud providers gated by explicit consent toggles

Dictation questions

Does Lausu need internet or a GPU?

No. Dictation and nine-pass cleanup run offline on standard CPUs. Whisper tiny uses 512 MB RAM; Parakeet Ultra uses 2 GB RAM.

Where do audio and API keys live?

Audio stays in RAM and drops after transcription. History stays in local SQLite for 90 days; optional keys stay in your OS keyring.

Is Lausu free for commercial work?

Yes. Lausu ships under the MIT License for Windows, macOS, and Linux (X11 & Wayland) with zero subscriptions or telemetry.
